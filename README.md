## Projetos em destaque

### 01 — [SAC Análises](https://github.com/Wtvitin/sac-analises)

**Sistema de gestão de ocorrências e rastreabilidade operacional.**

Aplicação web para registrar, investigar e acompanhar ocorrências relacionadas a pedidos. O projeto contempla gestão de casos, atribuição de responsáveis, controle de prazos, histórico auditável, perfis de acesso e recursos para acompanhamento operacional.

**Stack:** React · TypeScript · Vite · Node.js · Express · PostgreSQL · Prisma

**Destaques técnicos:** API com regras de negócio e validação, autenticação e autorização, trilha de auditoria, migrações versionadas e testes automatizados.

> Repositório de código público. O sistema não representa um serviço público de atendimento, e informações reais de clientes e credenciais não devem ser publicadas.

[**Explorar o projeto e sua documentação**](https://github.com/Wtvitin/sac-analises)
