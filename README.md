### 01 / SAC ANÁLISES

**Gestão de ocorrências • Rastreabilidade • Plataforma web**

<a href="https://github.com/Wtvitin/sac-analises">
  <img src="https://raw.githubusercontent.com/Wtvitin/Wtvitin/main/assets/sac-banner.png" alt="Banner do projeto SAC Análises — gestão de ocorrências, rastreabilidade, análise e resultados" width="100%" />
</a>

</div>

### O problema que o projeto resolve

Quando informações de um atendimento ficam espalhadas entre registros, mensagens e controles separados, acompanhar a situação de cada ocorrência se torna mais difícil. O **SAC Análises** foi desenvolvido para centralizar esse fluxo em uma aplicação, permitindo que cada caso tenha responsáveis, prazos, evidências e histórico de decisões.

### Como funciona

1. **Registro:** o usuário cadastra uma ocorrência com referências, informações pertinentes, itens e anexos.
2. **Acompanhamento:** a equipe consulta a fila, utiliza filtros e acompanha prioridades, responsáveis e prazos.
3. **Tratativa:** as atualizações do caso são registradas com comentários, mudanças de status e histórico de atividades.
4. **Gestão:** perfis de acesso, trilha de auditoria, notificações e indicadores apoiam a organização e a rastreabilidade.

**Por trás da interface:** o frontend em React e TypeScript conversa com uma API Express, responsável por autenticação, validação e regras de acesso. Os dados são persistidos no PostgreSQL por meio do Prisma. O repositório também documenta migrações, testes e verificações de qualidade.

### Uma central para organizar os estudos

O **EduTrack AI** reúne em um só ambiente as informações necessárias para acompanhar a rotina acadêmica. A proposta é diminuir a fragmentação entre listas de tarefas, calendários e registros de estudo, oferecendo uma visão mais clara das prioridades e do progresso.

### Como funciona

1. **Organização:** o estudante cadastra disciplinas e tarefas, definindo prazos, prioridade, dificuldade e tempo estimado.
2. **Planejamento:** o calendário apresenta compromissos acadêmicos e sessões de estudo; um cronômetro auxilia no registro do tempo dedicado.
3. **Acompanhamento:** dashboards e relatórios mostram pendências, atividades concluídas, atrasos, distribuição do esforço e evolução em diferentes períodos.
4. **Recursos inteligentes:** o projeto inclui um agente de IA autenticado, cuja disponibilidade depende da configuração de um provedor, e integração opcional de leitura com o Google Classroom.

**Arquitetura:** aplicação Next.js e React com TypeScript, persistência em PostgreSQL/PGlite, relatórios apoiados por Python e Pandas e controle de acesso por conta. O projeto possui demonstração separada dos dados de usuários autenticados.

### Aprendendo programação por meio de exercícios

Este repositório documenta meu processo de aprendizagem em **Lógica de Programação**, reunindo soluções em Python e organizando os conteúdos para facilitar a consulta, a revisão e a avaliação acadêmica.

### Como está organizado

1. **Primeiros algoritmos:** exercícios introdutórios de entrada, saída, operações e cálculos.
2. **Estruturas condicionais:** problemas com decisões, comparações, faixas de valores e validações.
3. **Funções e módulos:** prática de reutilização de código, escopo e funções matemáticas.
4. **Tuplas:** exercícios independentes sobre criação, acesso a elementos e imutabilidade, acompanhados de explicações e resultados esperados.

Cada etapa busca mostrar **não apenas o código, mas também o raciocínio aplicado**. As atividades são incrementadas conforme o avanço nos estudos.
